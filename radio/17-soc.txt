정보보안기사 실기 라디오. 17편. 관제센터의 하루.

오늘 나오는 용어는 아홉 개입니다. 이에스엠과 시엠, 로그 분석 단계, 소어, 보안 관제 세 가지 구성 요소, 이디알, 디엘피, 엔에이씨, 샌드박스, 그리고 사이버 킬 체인. 하루를 따라가면서 하나씩 만나 보겠습니다.


첫 번째 장면. 화면이 너무 많다.

이번 편은 개발자가 보안 관제센터에 하루 견학을 온 이야기입니다. 아침 아홉 시, 벽면 모니터에 경보가 끝없이 올라옵니다. 방화벽, 침입 탐지 시스템, 웹 방화벽, 서버, 백신에서 오는 경보입니다.

개발자가 말합니다. 장비가 이렇게 많은데 화면을 하나씩 다 보는 거예요?

박 선임이 답합니다. 예전에는 그랬어요. 그래서 여러 보안 장비의 이벤트를 한곳에 모아 보는 통합 보안 관리, 이에스엠이 나왔어요. 지금은 한 단계 더 나아가서 시엠을 써요. 시큐리티 인포메이션 앤드 이벤트 매니지먼트의 약자예요.

박 선임이 차이를 설명합니다. 이에스엠은 주로 보안 장비의 이벤트를 모아 실시간으로 보여 주는 데 초점이 있어요. 시엠은 보안 장비뿐 아니라 서버, 네트워크 장비, 애플리케이션 로그까지 대량으로 모아 오래 저장하고, 빅데이터 기반으로 연관 분석을 해요. 여러 장비에 흩어진 작은 신호를 엮어서 하나의 공격으로 찾아내는 거죠.

여기서 잠깐 떠올려 보세요. 여러 장비의 로그를 수집해 빅데이터 기반으로 분석하는 솔루션의 이름과 영문 약어는?

답입니다. 시엠, 에스 아이 이 엠입니다. 2026년 1회와 2회 실기에 연속으로 나왔습니다.


두 번째 장면. 로그가 경보가 되기까지.

개발자가 묻습니다. 장비마다 로그 모양이 다를 텐데 어떻게 한꺼번에 분석해요?

박 선임이 답합니다. 네 단계를 거쳐요. 기존 실기에 그대로 나온 순서예요.

첫째, 로그 수집입니다. 에이전트나 시스로그 방식으로 각 장비의 원본 로그를 시엠 서버로 가져와 저장합니다.
둘째, 로그 분류입니다. 같은 출발지와 목적지, 같은 포트처럼 비슷한 이벤트가 짧은 시간에 반복되면 묶어서 하나로 취합합니다.
셋째, 로그 변환입니다. 장비마다 다른 표현 형식을 표준 포맷으로 바꿉니다. 정규화라고도 합니다.
넷째, 로그 분석입니다. 정리된 로그로 상관 분석을 해서 공격을 찾습니다.

여기서 잠깐 떠올려 보세요. 유사한 이벤트를 묶는 단계와, 표현 형식을 표준으로 바꾸는 단계는 각각 무엇일까요?

답입니다. 묶는 단계는 로그 분류, 표준으로 바꾸는 단계는 로그 변환입니다.

박 선임이 관제 체계의 구성도 알려 줍니다. 각 장비와 서버에 설치돼 로그를 보내는 에이전트, 그 로그를 모아 처리하고 저장하는 정보 수집 서버, 모은 정보를 종합 분석해 관제 요원을 돕는 통합 관제 시스템. 이 세 가지가 2025년 2회 실기 서술형으로 나온 보안 관제 구성 요소입니다.

정리합니다. 로그 분석 단계. 수집, 분류, 변환, 분석. 보안 관제 구성 요소. 에이전트, 정보 수집 서버, 통합 관제 시스템.


세 번째 장면. 사람 대신 움직이는 플레이북.

오전 열한 시, 같은 해외 아이피가 웹 서버에 로그인을 수백 번 시도한다는 경보가 뜹니다. 그런데 관제 요원이 손대기 전에 그 아이피가 방화벽에 자동으로 차단됩니다.

개발자가 묻습니다. 누가 막은 거예요?

박 선임이 답합니다. 소어예요. 시큐리티 오케스트레이션, 오토메이션 앤드 리스폰스. 보안 오케스트레이션, 자동화, 대응이라는 뜻이에요. 정해진 상황이 생기면 플레이북이라는 대응 절차대로 여러 장비를 자동으로 움직여요. 이번에는 경보 확인, 아이피 평판 조회, 방화벽 차단, 담당자 알림까지 사람 손 없이 끝났어요.

개발자가 말합니다. 시엠이 찾고, 소어가 움직이는 거네요.

박 선임이 답합니다. 맞아요. 하루 수만 건의 경보를 사람이 다 처리할 수 없으니까요.

정리합니다. 소어. 플레이북에 따라 보안 장비를 연동해 대응을 자동화하는 솔루션.


네 번째 장면. 단말과 문서를 지키는 것들.

오후 두 시, 영업팀 피시에서 파워셸이 이상한 외부 주소로 접속을 시도한다는 경보가 올라옵니다. 백신은 아무것도 탐지하지 못한 상태였습니다.

박 선임이 말합니다. 이디알이 잡은 거예요. 엔드포인트 디텍션 앤드 리스폰스. 피시에 에이전트를 깔아 프로세스 실행, 파일 변경, 네트워크 연결 같은 행위를 계속 기록하고 분석해요. 알려진 악성코드 패턴이 없어도 수상한 행동을 보고 탐지하고, 그 피시를 네트워크에서 격리할 수도 있어요.

오후 세 시에는 다른 경보가 뜹니다. 퇴사 예정자가 고객 명단 파일을 유에스비 메모리에 복사하려다 막혔습니다.

박 선임이 말합니다. 디엘피예요. 데이터 로스 프리벤션, 정보 유출 방지 솔루션이죠. 중요 문서가 유에스비, 메일, 메신저, 웹 업로드로 나가는 걸 감시하고 차단해요. 2025년 2회 실기에는 이동식 디스크, 이메일, 메신저, 웹 업로드로 내부 문서가 나가는 것을 탐지하는 솔루션을 묻고 디엘피를 답으로 받았어요.

박 선임이 하나를 더 보여 줍니다. 외부 업체 직원이 노트북을 회의실 랜선에 꽂자, 인터넷이 안 되고 등록 안내 화면이 뜹니다.

박 선임이 말합니다. 엔에이씨, 네트워크 접근 제어예요. 네트워크에 붙기 전에 이 단말이 허가된 기기인지, 백신과 보안 패치가 최신인지 검사하고, 기준에 못 미치면 접속을 막거나 격리해요.

여기서 잠깐 떠올려 보세요. 단말 행위를 분석해 탐지하고 대응하는 솔루션, 내부 정보 유출을 막는 솔루션, 접속 전에 단말을 검사하는 솔루션. 각각 이름은?

답입니다. 이디알, 디엘피, 엔에이씨입니다.


다섯 번째 장면. 실행해 보고 판단한다.

오후 네 시, 메일 게이트웨이에서 첨부 파일 하나가 보류됩니다. 겉보기에는 견적서 문서입니다.

박 선임이 말합니다. 샌드박스로 보냈어요. 실제 업무 환경과 분리된 가상 환경에서 파일을 직접 실행해 보고, 레지스트리를 바꾸거나 외부로 접속하는 행위가 있는지 봐요. 악성이어도 격리된 공간이라 피해가 없죠. 2026년 2회 실기에 가상화 기술로 분리된 환경에서 악성 파일을 실행하는 기술을 묻고 샌드박스를 답으로 받았어요.

개발자가 묻습니다. 관제센터에서 쓰는 도구가 이게 전부예요?

박 선임이 답합니다. 점검 도구도 있어요. 트립와이어는 파일의 해시값을 저장해 두고 바뀌었는지 보는 무결성 점검 도구예요. 네서스는 미국 테너블사가 만든 취약점 스캐너고요. 둘 다 2026년 1회 실기에 나왔어요. 야라는 텍스트나 바이너리 패턴으로 악성코드를 찾는 규칙 도구예요.

정리합니다. 샌드박스. 격리된 가상 환경에서 실행해 행위로 판단. 트립와이어는 무결성, 네서스는 취약점 점검, 야라는 패턴 기반 악성코드 탐지.


여섯 번째 장면. 공격을 단계로 본다.

저녁 여섯 시, 박 선임이 하루 경보를 정리해 보고서를 씁니다.

박 선임이 말합니다. 오늘 본 경보들을 하나의 공격 흐름에 놓아 보면 이해가 쉬워요. 록히드 마틴이 만든 사이버 킬 체인이에요. 일곱 단계예요. 정찰, 무기화, 전달, 익스플로잇, 설치, 명령과 제어, 목표 달성.

개발자가 묻습니다. 그럼 오늘 견적서 첨부 파일은요?

박 선임이 답합니다. 메일로 보낸 건 전달 단계예요. 샌드박스가 거기서 끊었으니 익스플로잇과 설치로 못 넘어갔고요. 앞 단계에서 끊을수록 피해가 적어요. 이게 킬 체인을 쓰는 이유예요.

여기서 잠깐 떠올려 보세요. 마이터 어택과 비슷하지만 록히드 마틴이 제안한, 일곱 단계 공격 분석 모델의 이름은?

답입니다. 사이버 킬 체인입니다. 2025년 1회 실기에 그대로 나왔습니다.


오늘의 정리.

이에스엠은 보안 장비 이벤트 통합, 시엠은 다양한 로그를 빅데이터로 수집하고 연관 분석.
로그 분석 단계. 수집, 분류, 변환, 분석.
보안 관제 구성 요소. 에이전트, 정보 수집 서버, 통합 관제 시스템.
소어. 플레이북으로 대응 자동화.
이디알은 단말 행위 탐지와 대응, 디엘피는 정보 유출 방지, 엔에이씨는 접속 전 단말 검사.
샌드박스. 격리 환경에서 실행해 판단.
트립와이어는 무결성, 네서스는 취약점, 야라는 패턴.
사이버 킬 체인 일곱 단계. 정찰, 무기화, 전달, 익스플로잇, 설치, 명령과 제어, 목표 달성.

다음 편은 지사 연결 사건입니다. 아이피섹, 티엘에스, 하트블리드, 무선랜 보안을 만납니다.
