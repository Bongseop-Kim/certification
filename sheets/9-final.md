# 부록. 시험 직전 1장 덤프 시트

## 시험 직전 1장 덤프 시트

> 입실 직후 빈 종이에 **5분 안에** 쏟아낼 항목. 이것만 적어두면 계산·비교 문항에서 흔들리지 않는다.

### 숫자

- **AES 라운드 = (키/32) + 6** → 10 / 12 / 14 · **ARIA = +2** (12/14/16) · **LEA** 24/28/32
- **DES**: 블록 64 / 키 **56** / 16라운드 / Feistel · **HIGHT만 블록 64**
- **MD5** 128 / **SHA-1** 160 / SHA-2는 이름대로 · 블록 **512→64R, 1024→80R**
- **생일 공격 = 2^(n/2)**
- **키 개수**: 대칭 **n(n-1)/2**, 공개키 **2n**
- **ALE = SLE × ARO**, SLE = 자산가치 × EF
- 포트: 22 SSH / 25 SMTP / 53 DNS / 69 TFTP / 110 POP3 / 143 IMAP / 161 SNMP / 389 LDAP / 445 SMB / 500 IKE / 3389 RDP
- SetUID **4000** / SetGID **2000** / Sticky **1000** · umask 022 → 파일 644, 디렉터리 755
- ICMP: **8 요청 / 0 응답 / 3 도달불가(Code 3 = Port Unreachable) / 11 TTL 초과**
- IPSec: **AH = 51 / ESP = 50**, IKE 500/UDP

### 뒤집히기 쉬운 짝 — 정방향만 적기

| 짝 | 정방향 |
|---|---|
| BLP / Biba | **BLP = No Read Up + No Write Down** (Biba는 정반대) |
| ACL / CL | **ACL = 객체 기준**, CL = 주체 기준 |
| 오용 / 이상 탐지 | **오용 = 오탐 낮고 미탐 높음** |
| IDS / IPS | IDS 미러링(탐지), **IPS 인라인(차단)** |
| AH / ESP | **AH는 기밀성 없음** |
| 전송 / 터널 모드 | **터널 모드가 원본 IP 헤더까지 보호** |
| CRL / OCSP | **CRL 주기적, OCSP 실시간** |
| MAC / MDC / 서명 | **MAC은 부인방지 없음** |
| CPA / CCA | **CPA = 평문 선택**, CCA = 암호문 선택 |
| FAR / FRR | **FAR = 오인식(Type II, 더 위험)** |
| RTO / RPO | **RPO = 데이터 손실 허용 시점** |
| 증분 / 차등 | **증분 = 백업 빠름·복구 느림** |
| 위탁 / 제3자 제공 | **위탁 = 공개**, 제공 = 동의 |
| 가명 / 익명 | **가명정보는 개인정보** |
| 워터마킹 / 포렌식마킹 | **포렌식마킹 = 구매자 정보 → 유출자 추적** |
| Smurf / Fraggle | **Smurf = ICMP**, Fraggle = UDP |
| Slowloris / RUDY | **Slowloris = 미완성 헤더**, RUDY = POST 본문 |
| 델파이법 | **정성적** |
| FIN·NULL·XMAS | **열린 포트 = 무응답** |

### 순서

- 3-way: SYN → SYN/ACK → ACK
- 이중서명: 각각 해시 → 연결 → **다시 해시** → 개인키 서명
- Kerberos: AS → **TGT** → TGS → 서비스 티켓 → 서버
- 위험관리: 계획 → 분석 → 평가 → 대책 선정 → 계획서
- 침해사고: 준비 → 탐지 → 초기대응 → 전략체계화 → 조사 → 보고서 → 해결
- 복구센터: **미러 → 핫 → 웜 → 콜드**
- 휘발성: 레지스터 → **메모리** → 네트워크 → 프로세스 → 디스크 → 로그
- SSL Record: 단편화 → 압축 → MAC → 암호화 → 헤더

### 마지막에 확인할 것 (개정 가능 항목 — 암기 금지, 최신 조문 확인)

개인정보 유출 통지·신고 기한 및 기준 인원 / 과태료·과징금 액수 / 접속기록 보관 기간 / ISMS-P 인증기준 항목 수 / CISO·CPO 지정 의무 대상 범위
